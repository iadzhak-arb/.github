
# Arb — Scanner Platform

Архитектура проекта построена на основе микросервисов, что обеспечивает масштабируемость, независимое развертывание и чёткое разделение ответственности между компонентами.

## Архитектура системы

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Frontend  │────▶│   Backend   │────▶│   RabbitMQ  │
│   (React)   │◀────│  (Django)   │◀────│   (RMQ)     │
└─────────────┘     └─────────────┘     └─────────────┘
                               ▲                   │
                               │                   ▼
                       ┌─────────────┐     ┌─────────────┐
                       │   Nginx     │     │   Scanner   │
                       │   (Proxy)   │     │  (Python)   │
                       └─────────────┘     └─────────────┘
```

### Компоненты

| Компонент      | Описание                                          | Стек                   |
|----------------|---------------------------------------------------|------------------------|
| **Frontend**   | Веб-интерфейс торговой платформы                  | React, TypeScript, Vite|
| **Backend**    | REST API, управление данными, бизнес-логика       | Django, Python         |
| **Backend FastStream** | Асинхронный обработчик событий (consumer) | FastStream, Python     |
| **Scanner**    | Сканер рынка, сбор и анализ данных                | Python                 |
| **RabbitMQ**   | Брокер сообщений для асинхронного взаимодействия  | RabbitMQ               |
| **Nginx**      | Reverse proxy, раздача статики                    | Nginx                  |

### Взаимодействие сервисов

1. **Frontend** — клиентское приложение, обращается к Backend через REST API и через WebSocket (если используется)
2. **Backend** — основной сервер приложений, предоставляет API и работает с базой данных
3. **Backend FastStream** — асинхронный consumer, обрабатывает события из RabbitMQ
4. **Scanner** — сканирует рынок в реальном времени и публикует данные в RabbitMQ
5. **RabbitMQ** — централизованный брокер сообщений, связывает Scanner и Backend
6. **Nginx** — проксирует запросы к Backend и раздаёт статические файлы Frontend

## Быстрый старт

### Требования

- Docker
- Docker Compose

### Запуск

```bash
# Запуск всех сервисов
docker compose up --build

# Запуск в фоне
docker compose up --build -d
```

### Структура проекта

