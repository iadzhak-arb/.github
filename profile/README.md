
# Arb — Scanner Platform

Микросервисная платформа для поиска арбитражных возможностей на криптовалютных биржах. Система спроектирована для высокой нагрузки и независимого масштабирования компонентов: сбор данных, обработка событий и API работают как отдельные сервисы.

## Архитектура системы

Платформа построена по микросервисной модели с чётким разделением ответственности:

- **Сбор и расчёт данных** (Scanner + FastStream Worker) — работают асинхронно, публикуют/потребляют события через RabbitMQ.  
- **API‑слой** (Django + DRF) — предоставляет REST API, управляет бизнес‑логикой, правами доступа и подписками.  
- **Фронтенд** (React + TS + MUI) — клиентский интерфейс с фильтрами, таблицами и уведомлениями.  
- **Инфраструктурный слой** (Nginx, Traefik) — проксирование трафика, раздача статики, балансировка.


```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Frontend  │────▶│   Backend   │────▶│   RabbitMQ  │
│   (React)   │◀────│  (Django)   │◀────│   (RMQ)     │
└─────────────┘     └─────────────┘     └─────────────┘
                               ▲                   │
                               │                   ▼
                       ┌─────────────┐     ┌─────────────┐
                       │   Nginx     │     │   Scanner   │
                       │   (Proxy)   │     │  (Python)   │
                       └─────────────┘     └─────────────┘
```

### Компоненты

| Компонент      | Описание                                          | Стек                   |
|----------------|---------------------------------------------------|------------------------|
| **Frontend**   | Веб-интерфейс торговой платформы                  | React, TypeScript, Vite|
| **Backend**    | REST API, управление данными, бизнес-логика       | Django, Python         |
| **Backend FastStream** | Асинхронный обработчик событий (consumer) | FastStream, Python     |
| **Scanner**    | Сканер рынка, сбор и анализ данных                | Python                 |
| **RabbitMQ**   | Брокер сообщений для асинхронного взаимодействия  | RabbitMQ               |
| **Nginx**      | Reverse proxy, раздача статики                    | Nginx                  |

### Взаимодействие сервисов

1. **Frontend** — клиентское приложение, обращается к Backend через REST API и через WebSocket (если используется)
2. **Backend** — основной сервер приложений, предоставляет API и работает с базой данных
3. **Backend FastStream** — асинхронный consumer, обрабатывает события из RabbitMQ
4. **Scanner** — сканирует рынок в реальном времени и публикует данные в RabbitMQ
5. **RabbitMQ** — централизованный брокер сообщений, связывает Scanner и Backend
6. **Nginx** — проксирует запросы к Backend и раздаёт статические файлы Frontend

## Быстрый старт

### Требования

- Docker
- Docker Compose

### Запуск

```bash
# Запуск всех сервисов
docker compose up --build

# Запуск в фоне
docker compose up --build -d
```

### Структура проекта

```
.
├── frontend/          # Веб-клиент
├── backend/           # серверное API
├── scanner/           # Сканер рынка
├── docker-compose.yml # Конфигурация Docker
└── nginx.conf         # Конфигурация Nginx
```
